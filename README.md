# Heritage Short Pipeline

An automated, multi-stage Python and FFmpeg pipeline that turns a schema-validated storyboard (`storyboard.json`) into keyframes, motion clips, narration audio, background score, subtitles, an AI disclosure end card, and both **16:9** and **9:16** MP4 exports[cite: 2, 26].

## Quick Start

1. **Clone the repository and install Python dependencies:**
   ```bash
   git clone [https://github.com/JosefTewodros12/heritage-short-pipeline.git](https://github.com/JosefTewodros12/heritage-short-pipeline.git)
   cd heritage-short-pipeline
   pip install -r requirements.txt
   ```
